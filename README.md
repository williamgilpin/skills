# Claude skills

This repository is a collection of Claude skills. Each individual skill lives in its own directory under `skills/`.

## Use a skill

1. Choose a skill directory and make a ZIP of that directory, including its `SKILL.md` file.
2. In Claude Desktop or Claude on the web, open **Settings → Capabilities → Skills** and upload the ZIP.
3. Enable the skill, then use it in a chat.

Skills are managed per account, so an uploaded skill is available in both Desktop and web.
